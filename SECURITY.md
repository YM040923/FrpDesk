# Security Policy

FrpDesk does not yet have a dedicated, monitored vulnerability-reporting channel or a response-time commitment.

For a sensitive report, contact the maintainer through a private channel and do not publish exploit details, credentials, or personal data in an issue. Do not assume that a GitHub issue is private.

Configuration files may contain FRP tokens and are stored as ordinary local files under `%LOCALAPPDATA%\FrpDesk`; they are not encrypted by FrpDesk.
